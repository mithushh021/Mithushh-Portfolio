# Portfolio (React + Node)

## Setup
1. npm run install:all
2. Copy server/.env.example to server/.env and fill in the SMTP values
3. Paste your existing style.css into client/src/styles/style.css
4. In that file, delete the rule ".contact-info ion-icon { ... }" and append client/src/styles/additions.css
5. Put your images in client/public/assets/images/ and your CV in client/public/assets/
6. Terminal 1: npm run dev:server
   Terminal 2: npm run dev:client
